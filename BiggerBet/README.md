# Bigger Bet

**Cassino Intergaláctico: Onde você perde seu dinheiro na velocidade da luz**

A satirical, ultra-ironic web project built to raise awareness about the dangers of gambling and betting sites. Uses pure HTML5, CSS3, and Vanilla JS.

## Features
- **Satirical UI**: Neon, dark space theme featuring a "Black Hole Roulette" and a "Sadness Dashboard."
- **Gamification of Loss**: Simulates gambling mechanics without real money, instead rewarding you with ironic levels and achievements for "wasting your time."
- **Persistent Stats**: Uses `localStorage` to save your level, XP, consecutive days lost, and unlocked medals.

## How to Run
Since it is built with pure Vanilla JS and ES Modules, you need to run it via a local web server to avoid CORS issues with module imports.

1. Navigate to the project root directory.
2. Run a simple server:
   - Python 3: `python -m http.server 8000`
   - Node.js: `npx serve .`
3. Open `http://localhost:8000` in your browser.
